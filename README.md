## Portfolio Website – Frontend Practice Project

A modern and responsive personal portfolio website built for practice and demonstration purposes. This project showcases frontend design skills through a clean user interface and multiple website sections.

#Features
- Responsive design
- Home page
- About section
- Services section
- Project showcase
- Contact section
- Social media integration
- Clean and user-friendly interface

#Technologies Used
- HTML5
- CSS3

#Project Purpose
This project was developed to practice frontend web development and improve UI design skills. It is created for learning and portfolio showcase purposes.

#Note
This is a frontend-only project. Backend functionalities such as form submission or database integration are not implemented.
